#  Exercícios de Python — CET Programação e Sistemas de Informação

Repositório com exercícios práticos de Python desenvolvidos durante
o Curso de Especialização Tecnológica (CET) de Programação e
Sistemas de Informação.

## 📚 Conteúdos

### 🔐 Criptografia ASCII
Programa que criptografa e descriptografa mensagens usando a tabela
ASCII e uma chave em formato de string.

- Cálculo de chave numérica pela soma dos valores ASCII
- Criptografia caractere a caractere com `ord()` e `chr()`
- Descriptografia pela subtração da chave numérica
- Validação de chave vazia com `try/except`
- Boas práticas: uso de `if __name__ == "__main__"`

### 🔤 Ordenação de Nomes (Tabela ASCII)
Ordenação de nomes completos alfabeticamente com base nos valores
ASCII, sem uso de bibliotecas externas.

- Separação de primeiro nome e apelido com `.split()`
- Ordenação por primeiro nome como critério principal
- Desempate pelo apelido como critério secundário
- Implementação manual do algoritmo Bubble Sort

### ✅ Validação de Nomes com ASCII
Programa que valida se um nome completo respeita as regras de
formatação usando diretamente os códigos ASCII.

- Verificação de maiúsculas no início de cada palavra
- Validação de caracteres permitidos (letras e espaços)
- Paragem imediata ao encontrar um caractere inválido
- Uso de flags booleanas para controlo de estado

### 📦 Dicionários
Exercícios sobre criação, acesso, modificação e iteração
de dicionários em Python.

- Criar e listar dicionários
- Aceder e modificar valores
- Verificar existência de chaves
- Contar letras e palavras com dicionários
- Somar valores, inverter e juntar dicionários
- Calcular médias com dicionários aninhados

### 🔢 Ordenação (Sort)
Exercícios sobre algoritmos de ordenação e manipulação de listas.

- Ordenar palavras por ordem alfabética (A → Z)
- Ordenar palavras de forma inversa (Z → A)
- Ordenar caracteres de uma palavra
- Ordenar por critérios personalizados (nº de minúsculas)
- Agrupar e ordenar palavras por letra inicial
